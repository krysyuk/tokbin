# Contributing

The project is open for use and forks, but does not accept pull requests.
Suggestions, bugs and ideas go through issues: the author prioritizes them and
implements them personally. This keeps the style consistent and stability
guaranteed.

## Reporting a bug

Please include:

- the output of `tokbin doctor`;
- the full error text, including its code (`[TB-...]`);
- minimal steps to reproduce.

## Proposing a feature

Describe the problem to be solved first, and only then the solution.
